# 轻账本上架真机验收清单

> 适用版本：当前无提醒权限的发布基线。
> 执行原则：使用全新安装和已有数据升级各完成一次；每条 P0 未通过都不得提审。

## 构建与安装

- [ ] P0 使用 DevEco JBR 21 完成 `assembleHap`，产物时间戳为本次构建时间。
- [ ] P0 使用 AGC release 签名生成最终提交包，包名为 `com.lifeledger.app`。
- [ ] P0 在未安装旧包的真机上安装、启动、退出、再次启动均正常。
- [ ] P1 覆盖至少一台 HarmonyOS NEXT 真机和一台目标最低系统版本设备。

## 隐私与基础流程

- [ ] P0 首次启动显示隐私页；未同意时不进入主界面，也不初始化账本数据。
- [ ] P0 同意后进入首页；隐私政策与用户协议均可打开、返回。
- [ ] P0 应用内文案、AGC 隐私声明和 `privacy.md` 均说明纯本地、无网络、无运行时权限。
- [ ] P0 系统设置中的应用权限列表与 `module.json5` 一致。

## 核心账本

- [ ] P0 新建支出、收入、转账各一笔，金额、日期、账户、分类和统计口径正确。
- [ ] P0 在记账页快速连续点击顶部保存和键盘完成，只新增一笔流水；转账只生成一对互相关联流水。
- [ ] P0 记账页打开后切换到另一账本再返回，保存时不会把旧账本的账户或分类写入新账本；异常路由参数或已删除账户/分类会被拒绝。
- [ ] P0 删除任一转账记录后，配对记录同时消失。
- [ ] P0 转账记录左滑仅可删除、不可进入普通收支编辑；删除前明确提示会同时删除配对记录。
- [ ] P0 账户期初余额可录入负数；输入 `12abc`、多小数点或超大金额时不保存且提示金额不正确。
- [ ] P0 外币账户或预算打开后未改金额直接保存，基础货币金额不发生取整漂移；汇率输入 `7abc` 或越界值会被拒绝。
- [ ] P0 创建两个账本；在 A 记账后切换 B，明细、统计、账户、预算和导出均不显示 A 的数据；切回 A 后数据完整恢复。
- [ ] P0 有流水账本不可删除；无流水账本确认删除后，其账户、分类和预算一并消失。
- [ ] P1 设置 PIN、切至后台超过超时时间后重新进入，应用要求验证；忘记 PIN 的清库提示明确。

## 导出与备份恢复

- [ ] P0 CSV 导出成功后可在目标位置打开，中文列名和中文备注无乱码。
- [ ] P0 在系统保存面板取消导出时无错误 Toast；人为拒绝目标写入时显示失败提示。
- [ ] P0 备份后选择恢复，取消确认不会改变任何数据。
- [ ] P0 选择恢复文件后，应用先执行只读预检；损坏或不兼容文件不会显示覆盖确认，也不会修改当前数据。
- [ ] P0 备份后清空数据再恢复：账本、账户、分类、预算、流水及条数均与备份前一致。
- [ ] P0 负期初余额的账户备份后恢复，余额符号与金额保持一致。
- [ ] P0 用截断 JSON、超过 20MB 的文件、更高 schema_version、错误 app 标识和错误 row_counts 的 JSON 恢复，应用拒绝恢复且原有数据保持不变。
- [ ] P0 用账户/分类跨账本引用、断裂预算项或转账配对不完整的 JSON 恢复，应用拒绝恢复且原有数据保持不变。
- [ ] P1 导出诊断信息：文件只含版本、数据库状态与技术日志，不含账目、备注、账户/分类名称、PIN 或哈希。

## 上架材料核验

- [ ] P0 应用名称、图标、版本号、包名与 AGC 创建的应用一致。
- [ ] P0 截图展示真实功能，不含模拟数据中的敏感个人信息。
- [ ] P0 应用简介只描述已交付的本地记账、多账本、导出、备份恢复和应用锁功能。
- [ ] P0 隐私政策 URL 可访问，联系方式有效。
- [ ] P0 未实现每日记账提醒前，不提交代理提醒开放能力申请，也不在任何商店材料中宣称该功能。
